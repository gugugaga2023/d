# Java Basic

Bộ khung luyện tập Java dành cho người mới bắt đầu.

## Nội dung
- `Main.java`: chương trình đầu tiên
- `Variables.java`: biến
- `DataTypes.java`: kiểu dữ liệu
- `Operators.java`: toán tử
- `Conditions.java`: câu lệnh điều kiện
- `Loops.java`: vòng lặp
- `Arrays.java`: mảng
- `Methods.java`: phương thức

## Cách chạy
Cài JDK, mở terminal tại thư mục dự án rồi chạy ví dụ:

```bash
javac src/Main.java
java -cp src Main
```

Mỗi file có thể chạy độc lập bằng cách thay `Main` bằng tên lớp tương ứng.
